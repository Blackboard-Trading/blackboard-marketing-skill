# Blackboard marketing skill

An OpenAI skill for creating accurate Blackboard social content and image concepts using the current product mechanics and a bundled snapshot of the frontend's components, styles, and assets.

## Use

Place the `blackboard-marketing` directory in an agent's skills directory (for example, `.agents/skills/blackboard-marketing/`) so the agent can discover `SKILL.md`. The skill includes its reference files and frontend snapshot beside it.

Start with `SKILL.md`. For social planning, see `references/social-playbook.md`; for mechanism-sensitive copy, see `references/product-mechanics.md`; for art direction and reusable assets, see `references/visual-system.md` and `references/asset-catalog.md`.

## Included snapshot

The frontend source snapshot and its commit are recorded in `references/source-sync.md`. Refresh it when the application changes, and check the deployed network configuration before publishing any market, price, staking, House, or redemption claim.
